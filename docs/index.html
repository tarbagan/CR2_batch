CR2(RAW) Batch Studio

For photographers who prepare one Adobe Camera Raw / Photoshop XMP preset, then batch-render many Canon CR2 or other RAW files to JPG, review them, and move final picks into a delivery folder.

Release v1.1.0 Windows x64 .NET 8 WPF Adobe XMP / Photoshop
Download ZIP View Source

1. Create XMP In Photoshop

Open one Canon CR2/RAW file in Photoshop, adjust it in Camera Raw, and save the settings as an XMP file.

2. Run Batch Render

Start the app, keep Photoshop running, add RAW files, select the saved XMP preset, and render the whole batch to JPG.

3. Review The Output

Open the Review tab, zoom with the mouse wheel, drag the image in preview, and mark the best JPG files as final.

4. Move Final Picks

Send only selected JPG files into the final folder for delivery, retouching, AI steps, or social posting.

Requirements Adobe Photoshop with Camera Raw must be installed and should be running for CR2 + XMP -> JPG rendering through the Adobe engine.

How It Works / Как это работает

English

This app is made for photographers who already work in Adobe Photoshop / Camera Raw and want to apply one prepared RAW look to many files.

  1. Start Adobe Photoshop.
  2. Open one Canon CR2 or other RAW file.
  3. The file opens in Camera Raw. Adjust exposure, white balance, colors, sharpness and other RAW settings.
  4. Save these settings as an XMP preset or sidecar file.
  5. Open CR2RawBatchStudio.exe.
  6. Select that saved XMP file in the XMP preset field.
  7. Select the Out folder for rendered JPG files.
  8. Select the Final folder for selected best photos.
  9. Add all CR2/RAW files that should be processed with the same preset.
  10. Click Render. The app uses Photoshop to render RAW to JPG.
  11. Open the Review tab and sort the JPG output.
  12. Move the best images to the final folder.

Русский

Программа сделана для фотографов, которые уже работают в Adobe Photoshop / Camera Raw и хотят применить один подготовленный RAW-пресет сразу ко многим файлам.

  1. Запустите Adobe Photoshop.
  2. Откройте один файл Canon CR2 или другой RAW-файл.
  3. Файл откроется в Camera Raw. Настройте экспозицию, баланс белого, цвет, резкость и другие параметры RAW.
  4. Сохраните эти настройки как файл XMP или sidecar-файл.
  5. Откройте CR2RawBatchStudio.exe.
  6. В поле XMP preset выберите этот сохранённый XMP-файл.
  7. Укажите папку Out для готовых JPG.
  8. Укажите папку Final для лучших отобранных кадров.
  9. Добавьте все CR2/RAW-файлы, которые нужно обработать этим же пресетом.
  10. Нажмите Render. Программа использует Photoshop для рендера RAW в JPG.
  11. Перейдите на вкладку Review и отсортируйте полученные JPG.
  12. Переместите лучшие файлы в финальную папку.

XMP Preset / XMP-пресет

English

The key idea of the program is simple: you prepare one RAW look in Photoshop / Camera Raw, save it as XMP, and then apply that same look to the whole batch.

  • XMP is the settings file created from your RAW adjustments.
  • The app does not try to imitate Adobe rendering with third-party libraries.
  • Instead, it uses Adobe Photoshop so the result stays close to your normal workflow.

Русский

Главная идея программы простая: вы вручную делаете один вариант обработки RAW в Photoshop / Camera Raw, сохраняете его как XMP, а затем применяете этот же вариант ко всей серии файлов.

  • XMP — это файл с настройками вашей RAW-обработки.
  • Программа не пытается имитировать Adobe-рендеринг сторонними библиотеками.
  • Вместо этого она использует Adobe Photoshop, чтобы результат был максимально близким к вашему обычному workflow.

English

  • The app is intended for CR2/RAW batch workflow, not for replacing Photoshop editing.
