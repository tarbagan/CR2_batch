CR2 / RAW Batch

Add files or folders, build a queue, and process multiple RAW jobs in one pass.

Adobe XMP Workflow

Use XMP presets created in Adobe Camera Raw or Photoshop instead of trying to imitate Adobe processing.

Review And Final Pick

Sort JPG files, zoom with the mouse wheel, drag the image in preview, and send final shots to a delivery folder.

Portable Or Install

The package includes both the ready-to-run app files and a local installer script with Start menu and desktop shortcuts.

Requirements Adobe Photoshop with Camera Raw must be installed for CR2 + XMP -> JPG rendering through the Adobe engine.
About the Windows warning Windows SmartScreen can still show an unknown publisher warning even with icon and product metadata. To fully remove that warning, the installer/app must be signed with a trusted code signing certificate.
