CR2 Batch

Windows-приложение для пакетной обработки фотографий, применения Adobe XMP и экспорта RAW в JPG через Adobe Photoshop.

Скачать Windows ZIP Открыть GitHub

Что умеет

Пакетная очередь, выбор папок, применение XMP, экспорт JPG и подготовка к AI-обработке.

Adobe workflow

Для совпадения с Photoshop используется открытие RAW через Adobe Photoshop + Camera Raw.

Visual Studio

Исходники доступны в solution PhotoBatchStudio.sln.

Для корректного рендера CR2 + XMP -> JPG на компьютере должен быть установлен Adobe Photoshop с Camera Raw.
