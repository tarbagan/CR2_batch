Windows RAW Workflow

CR2(RAW) Batch Studio

For photographers who prepare one Adobe Camera Raw / Photoshop XMP preset, batch-render many Canon CR2 or other RAW files to JPG, review them, delete unwanted files from Out, and optionally run ONNX AI postprocess on selected frames.

Release v1.1.0 Windows x64 .NET 8 WPF Adobe XMP / Photoshop ONNX AI Postprocess
Download ZIP View Source

1. Create XMP In Photoshop

Open one Canon CR2/RAW file in Photoshop, adjust it in Camera Raw, and save the settings as an XMP file.

2. Run Batch Render

Start the app, keep Photoshop running, add RAW files, select the saved XMP preset, and render the whole batch to JPG in Out.

3. Review The Output

Open the Review tab, zoom with the mouse wheel, drag the image in preview, and delete unwanted JPG files from Out.

4. AI Postprocess

Load ONNX models from the models folder, choose a profile such as NAFNet-GoPro or NAFNet-REDS, and batch-process selected JPG files.

Requirements Adobe Photoshop with Camera Raw must be installed and should be running for CR2 + XMP -> JPG rendering through the Adobe engine.

How It Works / Как это работает

English

This app is made for photographers who already work in Adobe Photoshop / Camera Raw and want to apply one prepared RAW look to many files.

  1. Start Adobe Photoshop.
  2. Open one Canon CR2 or other RAW file.
  3. The file opens in Camera Raw. Adjust exposure, white balance, colors, sharpness and other RAW settings.
  4. Save these settings as an XMP preset or sidecar file.
  5. Open CR2RawBatchStudio.exe.
  6. Select that saved XMP file in the XMP preset field.
  7. Select the Out folder for rendered JPG files.
  8. Add all CR2/RAW files that should be processed with the same preset.
  9. Click Render. The app uses Photoshop to render RAW to JPG.
  10. Open the Review tab and sort the JPG output.
  11. Delete unwanted JPG files from Out.
  12. Use Step 3 if you want AI postprocess on selected files.

Русский

Программа сделана для фотографов, которые уже работают в Adobe Photoshop / Camera Raw и хотят применить один подготовленный RAW-пресет сразу ко многим файлам.

  1. Запустите Adobe Photoshop.
  2. Откройте один файл Canon CR2 или другой RAW-файл.
  3. Файл откроется в Camera Raw. Настройте экспозицию, баланс белого, цвет, резкость и другие параметры RAW.
  4. Сохраните эти настройки как файл XMP или sidecar-файл.
  5. Откройте CR2RawBatchStudio.exe.
  6. В поле XMP preset выберите этот сохранённый XMP-файл.
  7. Укажите папку Out для готовых JPG.
  8. Добавьте все CR2/RAW-файлы, которые нужно обработать этим же пресетом.
  9. Нажмите Render. Программа использует Photoshop для рендера RAW в JPG.
  10. Перейдите на вкладку Review и отсортируйте полученные JPG.
  11. Удаляйте ненужные JPG-файлы из Out.
  12. При необходимости перейдите на Step 3 и запустите ИИ-постобработку.

AI Postprocess / ИИ-постобработка

English

Step 3 reads JPG files from the Out folder, lets you mark which files should be processed, and applies one selected ONNX model to the checked files.

  • Place models into models\<ModelName>\.
  • Each model folder should contain an .onnx file and optional manifest.json.
  • NAFNet-GoPro is suited for blur removal on motion-blurred frames.
  • NAFNet-REDS is a more general restoration profile.
  • The processed JPG is written back into Out.

Русский

Шаг 3 читает JPG-файлы из папки Out, позволяет отметить, какие файлы нужно обработать, и применяет одну выбранную ONNX-модель к отмеченным файлам.

  • Положите модели в models\<ModelName>\.
  • В папке модели должен лежать файл .onnx и, при необходимости, manifest.json.
  • NAFNet-GoPro — профиль для удаления размытия.
  • NAFNet-REDS — более универсальный профиль восстановления.
  • Результат сохраняется обратно в Out.
